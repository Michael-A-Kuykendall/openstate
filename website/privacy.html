Privacy

Project state stays local.

The OpenState engine keeps project facts locally and sends no telemetry or project data; it contacts the license service only to check your license. Host history access and purchase services have the separate boundaries described below.

The software

  • The engine sends no telemetry. Host history discovery may contact the configured OpenCode API through its SDK; an API on another machine is not an offline history source.
  • License checks: the engine contacts Keygen (api.keygen.sh) to verify a license and, on the free tier, to count each structural apply, and the OpenState license worker once per machine to get a free-tier license. It sends the license key, a hashed machine fingerprint and the platform name; never project data, code or file names. A paid license works offline for up to 7 days between checks.
  • What OpenState records stays local. .openstate/ can be a directory, a symlink or a local pointer file. It can include your messages, the commands the agent runs and file paths, so treat it like shell history.
  • The installer downloads the release from GitHub; GitHub sees that request.

Buying it

  • Stripe processes the payment. Card details go to Stripe and are never seen by the seller.
  • Stripe shares your name and email with the seller. Keygen stores your license and a buyer account under that email, so you can recover a lost key: Keygen emails you a link to set its password.
  • A small Cloudflare worker connects Stripe to Keygen. It retains processed Stripe event ids for seven days to deduplicate webhook retries. This is a bounded retry guard, not a guarantee against every duplicate issuance.
  • Your email is used only to issue and manage your license and answer support. It is not sold or used for marketing.

This website

The site is hosted on GitHub Pages and loads fonts from Google Fonts, so GitHub and Google see your visit. It sets no cookies and runs no analytics.

Deleting your data

Email michaelallenkuykendall@gmail.com to have your Keygen record deleted. Stripe keeps payment records as the law requires.
