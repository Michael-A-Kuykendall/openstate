Privacy

Project state stays local.

The OpenState engine keeps project facts locally and sends no runtime telemetry or project data. Host history access and purchase services have the separate boundaries described below.

The software

  • The engine sends no runtime telemetry. Host history discovery may contact the configured OpenCode API through its SDK; an API on another machine is not an offline history source.
  • What OpenState records stays local. .openstate/ can be a directory, a symlink or a local pointer file. It can include your messages, the commands the agent runs and file paths, so treat it like shell history.
  • The installer downloads the release from GitHub; GitHub sees that request.

Buying it

  • Stripe processes the payment. Card details go to Stripe and are never seen by the seller.
  • Stripe shares your name and email with the seller. Keygen stores your license with that email.
  • A small Cloudflare worker connects Stripe to Keygen. It retains processed Stripe event ids for seven days to deduplicate webhook retries. This is a bounded retry guard, not a guarantee against every duplicate issuance.
  • Your email is used only to issue your license, handle refunds and answer support. It is not sold or used for marketing.

This website

The site is hosted on GitHub Pages and loads fonts from Google Fonts, so GitHub and Google see your visit. It sets no cookies and runs no analytics.

Deleting your data

Email michaelallenkuykendall@gmail.com to have your Keygen record deleted. Stripe keeps payment records as the law requires.
