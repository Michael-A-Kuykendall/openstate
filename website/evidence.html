Reads

A definition is a small part of its file.

  • 97%less data reading one function from a 63 KB file, in one measured case
  • 1.3 KBa definition read, against about 8.6 KB for an average file read
  • 22tools: search, read, navigate, and preview/apply edits
  • 18languages with symbol support; text tools work in any file

These are bytes returned per read in the maintainer’s sessions. How small a definition is next to its file depends on the code, and a careful agent can also read a range of lines.

Completion cost

Observed co-movement, not a controlled study.

In the maintainer’s OpenCode history, tokens per completed work item in the openstate project fell from about 16M to 10.6M (34%) and per commit from 16.0M to 11.05M (31%) between August and September 2026 while completions rose. A repo adopting the tools via Claude Code fell from 14.3M to 0.9M per commit. Non-adopting repos were flat or worse except one that improved in a lighter work phase.

No measurement yet shows fewer repeated failures. What OpenState guarantees is the record and its delivery to the agent.
