License

Keygen issues the key.

Stripe confirms the payment. The license worker then creates the Keygen license. OpenState does not add a second account system on top of that.

What happens after checkout

  1. Stripe sends checkout.session.completed to the worker.
  2. The worker reads keygen_policy_id from the Stripe product.
  3. Keygen creates the license and the success page shows the key.
  4. The install is still install.sh. The key is the entitlement record, not a second installer.

POST https://api.keygen.sh/v1/accounts/<account>/licenses

OpenState does not check the key at runtime and makes no network call; the key is your record of purchase. The success page shows it once. If you lose it, open a GitHub issue naming the email you used at Stripe checkout (never post a key), and the key is re-sent to that address.
