Which host remembers, and how.

Each host earns its receipt from tools/test-host-conformance.mjs: the gate verifies the owned registration rendering against goldens for all nine hosts, then — where the host binary is installed — runs the live gate (handshake, exact 36-tool list, state and structural calls, preview and apply refusals, restart) for a runtime receipt. Without the binary the receipt is schema-only: rendering verified, live checks not run.
