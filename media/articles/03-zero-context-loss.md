# Resume without re-reading

A session ends. A new one begins, and the agent faces the oldest question in
the trade: what was happening here? The transcript holds the answer, buried
in everything else that happened. Reading it back costs attention the new
session does not have yet.

---

## A note instead of a transcript

OpenState writes a resume note at the boundary: the current task, the files
in motion, the last check and whether it passed, what changed, what is still
open, and what to do next. The new session reads the note first and starts
from the noted place.

The note is built from the record, not from memory. What it says can be
traced back to the sessions where it happened.

---

## Measured reads

Structural reads return small, targeted results. A structural definition read
returned about 1.3 KB, against about 8.6 KB for an average file read.

In one measured case, reading a complete function from a 63 KB file returned
97% less data than reading the file.

These are bytes per read, not a token or money saving.

---

## What the note cannot do

The note carries state, not judgment. It says what was true when it was
written; the new session still has to check that it is true now. Sources,
windows and denominators: [measured evidence](../../docs/evidence.md).
