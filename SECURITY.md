## Reporting a Vulnerability

We take the security of openstate seriously. If you discover a security vulnerability, please follow these guidelines:

### 🔒 Private Disclosure Process

**DO NOT** create a public GitHub issue for security vulnerabilities.

Email [michaelallenkuykendall@gmail.com](mailto:michaelallenkuykendall@gmail.com?subject=SECURITY) privately and include "SECURITY" in the subject line. This is the supported vulnerability-reporting route. Do not include credentials, license keys or private customer data.

### 📋 What to Include

Please provide the following information in your report:

- **Description**: Clear description of the vulnerability
- **Impact**: What could an attacker accomplish?
- **Reproduction**: Step-by-step instructions to reproduce the issue
- **Environment**: OS, OpenCode version, openstate version

We aim to acknowledge reports within 48 hours and provide a remediation timeline within 7 days.
